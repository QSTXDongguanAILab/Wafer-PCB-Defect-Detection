# 基材擦花

> 初稿,待工艺确认。允收范围需由客户工艺部门给定。

## 判定依据

- 基材区域成片的细密纹路,方向大致一致,单条痕迹浅且无明确起止,整体呈"雾状/丝状"。
- 与「基材划痕」区分:擦花是多条浅痕成片,划痕是单条深痕。差分图上擦花表现为大面积低幅值差异。
- 常见诱因:板件叠放摩擦、传送带表面异物、清洗刷辊磨损、人工搬运未戴指套拖拽。

## 严重度分级

- **轻微**:仅绿油表面雾化,光泽度变化,无功能影响。
- **中等**:成片区域绿油变薄,局部见底。
- **严重**:擦花区域覆盖焊盘或细线路,影响可焊性或线宽。

## 处置步骤

1. 目视确认擦花范围与是否覆盖焊盘、细线区。
2. 轻微:按外观允收标准判定,通常放行;记录批次以便统计趋势。
3. 中等:交 QE 判定;必要时局部绿油补涂【需人工确认】。
4. 严重:判 NG【需人工确认】。
5. 擦花是典型的**批量性**缺陷 —— 一旦同批多板同区域出现,优先查搬运与清洗环节,而不是逐板返修。

## 复检标准

- 外观:光泽与色差在客户允收范围内。
- 可焊性:覆盖焊盘的板件需做可焊性验证后才能放行。
- 趋势:同批次擦花比例超过阈值时上报,按批拦截评估【需人工确认】。

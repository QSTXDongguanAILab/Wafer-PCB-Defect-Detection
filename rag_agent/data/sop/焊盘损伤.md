# 焊盘损伤

> 初稿,待工艺确认。本类是焊盘缺陷中风险最高的一类,允收判据须由客户工艺部门给定。

## 判定依据

- 焊盘本体发生几何缺损:缺角、变形、压伤、部分脱落、孔环破损。
- 与模板图对比:焊盘轮廓与模板不一致,面积或形状发生明显改变(不只是表面颜色变化)。
- 与「焊盘划痕」区分:划痕是表面层受损,轮廓完整;损伤是本体缺料,轮廓改变。
- 与「焊盘脏污/氧化」区分:后两者轮廓完整,仅颜色/反射率变化。

## 严重度分级

- **轻微**:焊盘边缘轻微缺口,剩余有效焊接面积仍满足客户标准(通常 ≥80%,以客户标准为准)。
- **中等**:有效焊接面积明显减少,或孔环单侧变窄但未破环。
- **严重**:焊盘大面积缺失、脱落、孔环破环(破环即通常判不可修)。

## 处置步骤

1. 测量剩余有效焊接面积与孔环最小宽度,对照客户允收标准。
2. 轻微:交 QE 判定后放行,记录位置与测量值。
3. 中等:做导通与可焊性测试;必要时按客户认可的返修工艺处理【需人工确认】。
4. 严重(破环 / 焊盘脱落):判 NG,通常不可返修,走报废流程【需人工确认】。
5. 焊盘脱落若成批出现,查压合/钻孔/电镀结合力,属结构性工艺问题,必须停线排查【需人工确认】。

## 复检标准

- 电性:导通测试必过;孔环相关缺陷需做互连可靠性验证。
- 尺寸:返修后焊盘尺寸与孔环宽度经测量确认达标。
- 记录:严重损伤样本留样归档,用于后续训练样本补充与责任追溯。

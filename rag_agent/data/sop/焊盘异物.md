# 焊盘异物

> 初稿,待工艺确认。导电异物一律按最严处理,不得放行。

## 判定依据

- 焊盘上出现有厚度的附着颗粒:锡渣、金属屑、绿油颗粒、纤维、胶带残留、板屑。
- 与模板图对比:焊盘区域出现**凸起/多料**类差异(差分为正向),边界清晰、有明显高反差。
- 与「焊盘脏污」区分:异物有体积,差分幅值大且集中;脏污是薄层污渍,差分平缓。
- 与「焊盘损伤」区分:异物是多料,损伤是缺料。

## 严重度分级

- **轻微**:非导电的松散异物,可清除且清除后焊盘完好。
- **中等**:非导电异物附着牢固,或已被表面处理层部分包覆。
- **严重**:**导电异物**(锡渣、金属屑),或异物跨接相邻焊盘/线路。

## 处置步骤

1. **第一步判断是否导电** —— 锡渣与金属屑存在桥连短路风险,直接按严重处理,不允许目视放行。
2. 轻微:按清洗/离子风作业指导清除,清除后复判确认差异消除。
3. 中等:清除后做可焊性测试;固化在镀层内的交 QE 判定【需人工确认】。
4. 严重(导电异物或跨接):判 NG,做绝缘/耐压测试,不合格报废【需人工确认】。
5. 锡渣类异物集中出现,查喷锡/回流/切割工序与除尘;金属屑集中出现,查钻孔与铣边工位。

## 复检标准

- 清除后重新过 AVI 或本系统复判,差分应消除。
- 跨接过焊盘的位置必须通过绝缘/耐压测试。
- 可焊性测试合格。
- 记录异物形态与来源推断,用于工序整改与训练样本补充。

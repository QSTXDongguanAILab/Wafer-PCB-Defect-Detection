# 假点

> 初稿,待工艺确认。假点不是缺陷,本篇的处置结论是**放行**。

## 判定依据

- AVI 报点位置在待检图与模板图上无实质差异,或差异来自光照、对位偏移、油墨色差等成像因素。
- 常见诱因:曝光波动、板面反光、AVI 对位偏移一两个像素、绿油颜色批次差、V-Cut 边缘阴影。
- 假点在 AVI 报点中占比约三分之一,是本系统要过滤掉的主要对象。

## 严重度分级

不分级。假点无质量影响。

## 处置步骤

1. 确认模型给出的假点概率高于放行阈值(默认 0.90)。低于阈值的一律转人工复检,不得直接放行。
2. 板件直接进 OK 流,不做任何返修动作。
3. 记录落库,计入自动放行统计。

## 复检标准

- 抽检:按批次抽取一定比例的自动放行样本交人工目视确认,用于监控漏检。
- 一旦抽检发现真缺陷被放行,立即上调放行阈值并复盘该样本,同时排查是否需要补充该缺陷类型的训练样本。

## 注意

假点比例异常升高(例如某个 AVI 检测项突然大量报点)通常不是板子的问题,
而是 AVI 参数或光源状态发生了变化,应反馈设备侧检查,而不是简单放行了事。

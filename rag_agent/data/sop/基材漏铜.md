# 基材漏铜

> 初稿,待工艺确认。允收判据(暴露面积、位置)需由客户工艺部门给定。

## 判定依据

- 应被绿油覆盖的基材区域出现铜面暴露,呈现铜色/金属光泽,与模板图对比亮度与色相同时变化。
- 常见诱因:绿油印刷偏位、曝光对位偏差、显影过度、绿油附着不良脱落、后段刮碰导致绿油剥离。
- 对应 AVI 检测项常为「漏铜」「绿油铜均匀度」。

## 严重度分级

- **轻微**:暴露面积小且远离焊盘与相邻线路,无短路与氧化扩散风险。
- **中等**:暴露面积较大,或靠近相邻线路但未跨接。
- **严重**:暴露铜面跨接相邻线路、位于金手指/高压区,或大面积暴露导致后续氧化。

## 处置步骤

1. 测量暴露区域尺寸与到相邻导体的最小间距。
2. 判断是否属于设计允许的开窗区(对照 Gerber/阻焊层)——设计开窗不算缺陷,应归假点。
3. 轻微:按外观允收标准判定,通常可放行。
4. 中等:绿油局部补涂后复检【需人工确认】。
5. 严重:判 NG;跨接导体的必须做绝缘测试,不合格报废【需人工确认】。
6. 同一位置批量出现,查绿油印刷对位、曝光菲林与显影参数,属工艺偏移而非偶发。

## 复检标准

- 补涂后绿油覆盖完整、厚度与附着力达标,且不侵入焊盘。
- 暴露过的铜面需确认无氧化变色;已氧化的按「焊盘氧化」流程一并处理。
- 绝缘/耐压测试通过。

# 基材划痕

> 初稿,待工艺确认。判据中的具体尺寸门槛需由客户工艺部门给定。

## 判定依据

- 基材(绿油/介质层)区域出现细长条状痕迹,方向性明显,与模板图对比有明确的亮度差。
- 与「基材擦花」区分:划痕是单条、边界清晰、有明确起止;擦花是成片的细密纹路。
- 与「基材异物」区分:划痕是凹陷/去除类,异物是附着/凸起类,差分图上符号相反。

## 严重度分级

- **轻微**:仅绿油表层受损,未见铜层暴露,不影响绝缘。
- **中等**:绿油划穿见底,但线路铜箔完好。
- **严重**:伤及线路铜箔,存在线宽减小或断线风险 —— 此时按开路/线宽不足类缺陷升级处理。

## 处置步骤

1. 目视复核划痕是否伤及线路;伤及线路的转电性测试确认导通。
2. 轻微:绿油表层伤,按客户外观允收标准判定,通常可放行。
3. 中等:记录位置与长度,交 QE 依允收标准判定是否需要绿油补涂【需人工确认】。
4. 严重(伤铜):判 NG,走报废或返修流程【需人工确认】。
5. 连续同位置出现时,排查该工位的传送轨道、治具、操作手法是否存在硬物刮碰。

## 复检标准

- 电性:伤及铜层的板件必须通过导通/绝缘测试。
- 外观:补涂后绿油厚度与附着力符合客户标准。
- 追溯:同板号、同位置重复出现三次以上,应视为工装问题而非偶发,反馈产线整改。

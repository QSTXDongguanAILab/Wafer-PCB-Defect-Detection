# 基材异物

> 初稿,待工艺确认。原始数据中该类带严重度后缀(如「基材异物-中等」),
> 本系统已归一为「基材异物」,严重度由下面的分级判定。

## 判定依据

- 基材区域出现附着物,与模板图对比为**凸起/多料**类差异(差分为正向),边界清晰。
- 常见形态:粉尘、纤维、绿油颗粒、锡渣、胶带残留、其他板屑。
- 与「基材划痕/擦花」区分:异物是多料,划痕擦花是缺料,差分符号相反。
- 关键区分:**可去除 vs 不可去除**。浮尘类可清洗后转合格;固化在绿油内的颗粒属永久缺陷。

## 严重度分级

- **轻微**:浮于表面的松散异物,可用无水乙醇/离子风清除,清除后无痕。
- **中等**:异物附着较牢或已被绿油部分包覆,清除后留有痕迹。
- **严重**:异物跨接两条相邻线路,或位于高压/细间距区域,存在短路与绝缘风险。

## 处置步骤

1. 先判断异物是否**导电**(锡渣、金属屑)。导电异物一律按严重处理,不得放行。
2. 轻微:按清洗作业指导清除,清除后复检外观与差分是否消除。
3. 中等:交 QE 判定;固化在绿油内的按外观允收标准判定【需人工确认】。
4. 严重(跨接线路/导电异物):判 NG,做绝缘测试;不合格则报废【需人工确认】。
5. 同批集中出现时,查上道工序的环境洁净度、除尘设备、周转载具。

## 复检标准

- 清除后重新过 AVI 或本系统复判,差分应消除。
- 跨接过线路的位置必须通过绝缘/耐压测试。
- 记录异物形态,便于统计来源(粉尘 / 锡渣 / 纤维)并针对性整改。

# 焊盘脏污

> 初稿,待工艺确认。清洗工艺与药水须按客户认可的作业指导执行。

## 判定依据

- 焊盘表面附着外来污物:油污、指纹、药水残留、助焊剂残留、粉尘、水渍。
- 与模板图对比:焊盘区域出现不规则的暗斑或色块,边界清晰、形状随机,焊盘轮廓完整。
- 与「焊盘氧化」区分:脏污是外来附着、形状随机;氧化是自身变色、渐变均匀。多数脏污**可清洗恢复**,氧化不能。
- 与「焊盘异物」区分:脏污是薄层污渍,异物是有厚度的颗粒物,差分幅值更大。

## 严重度分级

- **轻微**:少量浮尘或水渍,清洗即可完全去除。
- **中等**:油污/指纹/助焊剂残留,需按清洗流程处理,清除后无痕。
- **严重**:药水残留已侵蚀表面处理层,或污物无法清除。

## 处置步骤

1. 判断污物性质:水渍/浮尘 → 清洗;油污/指纹 → 按清洗作业指导用指定溶剂;药水残留 → 需评估是否已侵蚀镀层。
2. 轻微、中等:执行清洗,清洗后重新过 AVI 或本系统复判,差异应消除。
3. 清洗后仍有痕迹的,做可焊性测试后交 QE 判定【需人工确认】。
4. 严重(侵蚀镀层 / 不可清除):按「焊盘氧化」或「焊盘损伤」流程升级处理,必要时判 NG【需人工确认】。
5. 指纹类脏污集中出现,查作业员是否规范戴手套/指套;药水残留集中出现,查水洗段清洗效果。

## 复检标准

- 清洗后外观无残留痕迹,复判无差异。
- 可焊性测试合格。
- 清洗次数与所用溶剂需记录,避免反复清洗损伤表面处理层。

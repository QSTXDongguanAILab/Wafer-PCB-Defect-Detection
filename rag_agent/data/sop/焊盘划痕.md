# 焊盘划痕

> 初稿,待工艺确认。焊盘缺陷直接影响可焊性,允收判据须由客户工艺部门给定。

## 判定依据

- 焊盘表面出现细长条状痕迹,表面处理层(OSP / 化金 / 喷锡)被破坏,常露出底铜。
- 与模板图对比:焊盘区域出现明显的线状亮度差,方向性强。
- 对应 AVI 检测项常为「大焊盘均匀度」「大孔环均匀度」「大焊盘1」。

## 严重度分级

- **轻微**:仅表面处理层轻微擦伤,底铜未露,痕迹在焊盘边缘。
- **中等**:表面处理层划穿露底铜,但划痕未跨过焊盘中心区。
- **严重**:划痕贯穿焊盘、伤及焊盘边缘导致有效焊接面积减少,或位于 BGA/细间距焊盘。

## 处置步骤

1. 目视确认是否露出底铜 —— 露铜即存在氧化与虚焊风险,不得按轻微处理。
2. 轻微:按外观允收标准判定,通常可放行;记录位置。
3. 中等:做可焊性验证;必要时局部补做表面处理【需人工确认】。
4. 严重(有效焊接面积不足 / 关键焊盘):判 NG,报废或返修【需人工确认】。
5. 焊盘划痕通常来自后段搬运与测试探针,重复出现时优先查 ICT 探针位置与治具定位。

## 复检标准

- 可焊性:按客户标准做润湿测试,焊料应完整覆盖焊盘。
- 外观:补做表面处理后颜色均匀、无残留药水痕。
- 追溯:同位置重复出现视为治具问题,反馈整改而非逐板返修。

# 焊盘氧化

> 初稿,待工艺确认。氧化允收判据与重工次数上限须由客户工艺部门给定。

## 判定依据

- 焊盘颜色变暗、发黄、发红或呈彩虹色,失去金属光泽;焊盘轮廓完整、无缺料。
- 与模板图对比:焊盘区域整体色相与反射率变化,而几何形状不变。
- 与「焊盘脏污」区分:氧化是焊盘自身表面化学变化,颜色渐变均匀;脏污是外来附着物,边界清晰、形状随机。
- 常见诱因:OSP 膜失效、板件裸放超期、湿气侵入、包装未真空、库存超期、水洗后未及时烘干。

## 严重度分级

- **轻微**:局部轻微变色,可焊性测试仍合格。
- **中等**:成片变色,可焊性下降但可通过重工恢复。
- **严重**:氧化层厚、出现绿色/黑色氧化产物,或已超过客户允许的重工次数。

## 处置步骤

1. 先确认是**个别焊盘**还是**整板/整批** —— 氧化几乎总是批量性问题,单点氧化更可能是脏污误判。
2. 做可焊性测试(润湿平衡或浸锡测试),以测试结果而非目视为准。
3. 轻微且可焊性合格:放行,但需缩短后续存放期限并标注。
4. 中等:按客户认可的工艺做去氧化/重新表面处理【需人工确认】;记录重工次数。
5. 严重或超重工次数:判 NG,报废【需人工确认】。
6. 整批氧化时评估批量拦截,并查包装、库存周期与车间湿度【需人工确认】。

## 复检标准

- 可焊性测试合格是放行的**硬条件**,不能只看外观。
- 重工后需重新计入重工次数并在履历中记录。
- 环境:确认车间温湿度与真空包装状态已整改,否则重工后仍会复发。
